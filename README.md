# AI — Personal Archive

A single place to keep my coding projects, documentation, books, and notes.

## Layout

| Folder | What goes here |
|---|---|
| [`code/`](code/) | Coding projects, scripts, experiments (one subfolder per project) |
| [`docs/`](docs/) | Documentation, guides, how-tos, reference write-ups |
| [`books/`](books/) | Book manuscripts, chapters, drafts, and reading notes |
| [`notes/`](notes/) | Quick notes, ideas, journals, scratch thoughts |

The existing `backend/`, `frontend/`, and `tests/` folders are an earlier app project and are left in place.

## Tips

- Use Markdown (`.md`) for writing — GitHub renders it nicely and it diffs well.
- Name files with dates or clear titles, e.g. `2026-10-10-idea.md` or `chapter-01.md`.
- Avoid committing secrets (API keys, passwords). `.env` files are already ignored.
- GitHub rejects files over 100 MB; keep large PDFs/media elsewhere or use Git LFS.
